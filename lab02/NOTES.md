Git -- это программа, которую разработчик устанавлвает на свой компьютер. Её основная задача -- отслеживать изменения в файлах 
проекта, сохранять историю этих изменений и позволять откатываться к предыдущим версиям.
GitHub --  это онлайн-сервис, который предоставляет облачное хранилище для Git-репозиториев и добавляет инструменты для 
совместной работы. 

Использованные команды:
git status
Эта команда даёт обзор состояния репозитория. Она показывает:
Какие файлы уже добавлены в индекс (staged) и готовы к следующему коммиту.
Какие файлы изменены в рабочей директории, но ещё не добавлены в индекс.
Какие новые файлы появились в проекте и Git о них пока не знает (неотслеживаемые файлы).

git diff
Команда git diff показывает различия между двумя состояниями. Без аргументов она сравнивает рабочую директорию с индексом, то есть выводит изменения, которые ещё не были добавлены через git add

git diff --staged
Эта команда показывает разницу между индексом и последним коммитом (HEAD). То есть она демонстрирует изменения, которые уже подготовлены к коммиту и будут включены в следующий коммит. 
Важный нюанс: если вы уже выполнили git add, но затем изменили файл в рабочей директории и хотите посмотреть именно проиндексированные правки, а не те, что ещё только редактируются, используйте именно эту команду (git diff --staged), иначе git diff без аргументов покажет только изменения, не попавшие в индекc

git status — чтобы понять общую картину: что уже готово к коммиту, что нужно добавить, а что — новый файл.
git diff — чтобы увидеть детали изменений в рабочей директории (что ещё не добавлено в индекс).
git diff --staged — чтобы проверить, что именно попало в индекс и будет закоммичено.
git add — чтобы переместить нужные изменения из рабочей директории в индекс.
git commit — чтобы сохранить снимок из индекса в репозиторий
